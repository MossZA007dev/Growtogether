Glow Together สำหรับโฮสต์เว็บ HTTPS
1. แตกไฟล์และอัปโหลดไฟล์ทั้งหมดไว้ในโฟลเดอร์หลักของเว็บ
2. ถ้าใช้ GitHub Pages ให้อัปโหลดไฟล์ไปยังรีโพสำหรับแอป แล้วไปที่ Settings → Pages → Deploy from a branch เลือก main และ /(root)
3. เปิด URL ที่โฮสต์ให้ใน Safari แล้วเลือกแชร์ → เพิ่มไปยังหน้าจอโฮม
4. ย้ายข้อมูลจากเว็บเดิมผ่าน โปรไฟล์ → ดาวน์โหลดไฟล์สำรอง แล้วนำเข้าบน URL ใหม่

อัปโหลดเฉพาะไฟล์ในชุดนี้ เก็บไฟล์สำรอง .json ที่มีข้อมูลและรูปไว้ในเครื่อง
GitHub Pages https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
